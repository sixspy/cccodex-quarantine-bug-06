# cc-quarantine-lab

CC_Codex 二期（26.11）**数据工程**产品线：**抓取隔离舱检疫台**（Pyramid + Waitress + 原生 JS SPA 右侧抽屉 + SQLite）。

## 一句话骨架

**抓取批次 → 坏件入隔离舱 → 复核放行 / 回炉重抓 → 隔离对账**

## 游标断点（甲路：独立游标队列）

抓取侧读引用唯一绑定各源站的**队列头**（`capture_cursors` 中 `status='队列头'`
的断点落点行），不存在第二套游标引用，结构上禁双开：

- **落点行**：每次落断点在单事务内写定一行（源站、当刻页键、末条目键、
  sha256 指纹链、版本），旧头归档；无落点行时重抽请求直接拒绝，禁止整页重抽。
- **指纹链**：`sha256(源站|页键|末条目键|前指纹)`；推进必须携带当前队列头指纹，
  歪指纹/旧游标回刷一律白话拒绝，事务整体回滚。
- **串行**：`cursor_locks` 源站锁 + 队列头 partial unique index 双保险，
  同源站并发提交只允许一个写定。
- **重抽计数**：仅按断点重抽成功单 +1；同源已见条目键去重并累计“拦截重复灌舱”。
- **四页贯通**：抓取列表亮断点芯片（落点行推导）、舱卡亮重抽次数、
  对账页挂游标摘要、台参数页只读断点口径。

与血缘影响、压实合并、回灌切片、契约换版、水印盖印、清单闭合、留存裁撤**正交**；不做 CDC 游标 / Feed 归并 / Slicegate 类指纹。
